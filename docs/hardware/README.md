# 硬件资料

主线见 [H20](h20.md)，扩展见 [B 系列](blackwell.md)。当前尚未采集实际设备信息。

先阅读 [线程与执行](execution.md) 和 [存储与数据访问](memory.md)，再查参数。参数需要能对应到一个代码决策。接着用 [资源预算练习](resource-budget.md) 手算分块、缓冲区和同时驻留的块数。

| 参数 | 白话含义 | 对代码的影响 |
| --- | --- | --- |
| 计算能力版本 | 支持哪些硬件功能和指令 | 编译目标与可用实现 |
| SM 数 | 有多少计算单元可安排块 | 工作量是否足够分散 |
| 显存容量 | 能同时保存多少数据 | 输入和中间结果是否放得下 |
| 显存带宽 | 每秒可搬运多少数据 | 大数组读写的时间尺度 |
| 寄存器 / SM | 同时保留线程私有值的空间 | 每线程结果数量与驻留块数 |
| 共享内存 / 块、/ SM | 一个块及一个 SM 可使用的共享空间 | 分块大小和缓冲区数量 |
| L2 容量 | 可缓存的数据规模 | 不同输入规模的重复读取行为 |
| 指定精度的运算速度 | 对应计算路径每秒能做多少运算 | 不能混用 FP32 与 Tensor Core 上界 |

计算能力表示功能版本，不是性能排名；每项限制还需区分每线程、每块与每 SM。[NVIDIA 计算能力说明](https://docs.nvidia.com/cuda/cuda-programming-guide/05-appendices/compute-capabilities.html)

每张参数卡记录具体型号、计算能力、SM 数、显存容量和带宽、缓存、寄存器与共享内存限制、各精度计算能力，以及来源和核验日期。明确区分设备级与 SM 级参数、稠密与稀疏计算口径。

官方理论值与本机实测值分开保存。参数后配对应实验，解释它影响了什么，例如分块大小、并发线程数和数据复用。
