## 从基础走向 Hopper 实现

先完成普通分块与同步，再按以下顺序阅读 Hopper 功能：

| 功能 | 解决什么问题 | 先掌握什么 |
| --- | --- | --- |
| Tensor Core | 用专门硬件执行矩阵运算 | GEMM、数据布局和累加精度 |
| TMA | 由专门单元搬运整块张量数据 | 共享内存、对齐、等待完成 |
| 搬运与计算分工 | 部分 warp 准备数据，其他 warp 计算 | warp、缓冲区与同步 |
| 块组成 cluster | 在受支持的块组内协作 | 普通块的同步边界 |

这些是架构学习入口；使用前仍需核对实际设备、编译目标与所选实现的要求。[NVIDIA Hopper Tuning Guide](https://docs.nvidia.com/cuda/hopper-tuning-guide/index.html)

```text
原理示意：两块缓冲区交替使用

普通顺序：搬第 0 块 → 算第 0 块 → 搬第 1 块 → 算第 1 块
尝试重叠：搬第 0 块 → [算第 0 块，同时搬第 1 块] → 算第 1 块
```

是否真能重叠、缓冲区何时可以覆盖，都需要正确同步并实际测量。Hopper 指南中的 H100 整卡参数不直接填入 H20 参数卡。
