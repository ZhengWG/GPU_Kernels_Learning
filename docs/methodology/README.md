# 实验与验证规范

状态：规范已建立，公共工具待实现。

## 实验目录

每个实验包含 README、完整实现、独立 reference、正确性测试、计时脚本和输入配置。图放在 figures/，可选交互演示放在 interactive/；有实测之后再写性能分析。

## 正确性

说明公式、尺寸、数据类型、内存布局、累加精度和支持范围。覆盖固定随机种子、不能整齐分块的尺寸及适用的数值边界。按数据类型设置绝对与相对误差，不为使测试通过而任意放宽。对于反向计算还需验证梯度。

使用 GPU 内存与同步检查工具检查适用实验。不支持的输入必须拒绝，或明确记录替代路径。

## 性能

先验证正确性，再预热和计时。编译、输入生成与分配默认排除在 kernel 计时之外；如测端到端时间，单独报告并说明包含项。正确处理 GPU 异步执行，报告重复次数与结果波动。

对照上一版教学实现以及适用的成熟库。比较时保持数学语义、数据类型、精度和布局一致；必要的数据转换开销明确列出。使用多组有代表性的输入，保留变慢的结果。

记录具体 GPU、驱动、Toolkit、依赖、编译选项、代码版本、输入、命令和原始结果。性能分析工具可能影响耗时，分析采样与正常计时分开执行。
