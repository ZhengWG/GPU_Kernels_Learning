# 02 硬件与测量

状态：背景讲解已有初版，配套 GPU 微实验待实现。

阅读 [硬件参数含义](../../docs/hardware/README.md)、[存储与数据访问](../../docs/hardware/memory.md)、[性能判断](../../docs/methodology/performance-basics.md)。

无 GPU 时可继续阅读 [经典算子的计算方式](operator-patterns.md)，完成手算与自测。
