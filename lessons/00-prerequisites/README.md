# 00 必要背景

状态：背景讲解已有初版，完整 GPU 实验待实现。

依次阅读：

1. [从 Python 到 C++](../../docs/prerequisites/01-python-to-cpp.md)：读懂指针、类型与启动语法。
2. [张量与内存布局](../../docs/prerequisites/02-tensors-and-layout.md)：手算二维索引与转置步长。
3. [计算所需数学](../../docs/prerequisites/03-math-for-kernels.md)：画出 GEMM 和 Attention 的输入输出。
4. [浮点数与误差](../../docs/prerequisites/04-floating-point.md)：知道如何判断正确性。

完成各篇自测即可进入 CUDA 入门。无需先学复杂 C++ 模板。完整导航见 [背景入口](../../docs/prerequisites/README.md)。
