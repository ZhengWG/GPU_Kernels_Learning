# 05 综合实践

当前先做无 GPU 的理论作业：从一个数学定义出发，完成输入约定、数据图和可验证推导。

## 作业：为一个算子写清楚设计

选择矩阵转置、行 Softmax 或 RMSNorm，提交以下内容：

1. 输入输出的 shape、dtype、stride 与支持范围。
2. 一张线程与元素对应图，一张数据搬运图。
3. 数学参考与尾部、零值等有意义的边界检查。
4. 预计计算量、逻辑读写量，以及这些估算的假设。
5. 两个候选优化，每个说明收益来源、资源代价和待验证项。

对照 [KDA / KDA-Pilot](../../case_studies/kda_pilot/README.md) 完善验证约定，对照 [SOLAR](../../case_studies/solar/README.md) 检查性能估算口径。
